# STORY CARDS FOLDER
## Collection of User Story Examples for Test Case Generation

This folder contains story card examples that follow the prompt template format. Each story card can be used to generate comprehensive test cases using the Site-Specific Test Case Generator.

### Purpose:
- Store user story examples for different Mayo Clinic Patient Platform modules
- Demonstrate proper format for story cards
- Provide templates for different sprint scenarios
- Support multi-sprint test case generation and regression analysis

### Usage:
1. Add story card files following the prompt template structure
2. Use story cards as input for test case generation
3. Generate sprint test cases using individual story cards
4. Create regression test suites by combining multiple sprint story cards

### File Naming Convention:
- Sprint_XX_StoryCard_ModuleName.md
- Example: Sprint_13_StoryCard_Messages.md, Sprint_14_StoryCard_Appointments.md
